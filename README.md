# 策展中的澳门：一条路线如何编排跨文化身份

> *Curating Macau: How One Route Stages Intercultural Identity*

HKUST(GZ) UCUG1600 跨文化交流课程 final presentation 与 final report 项目。项目基于澳门 field trip 的照片、视频、路线记录和现场观察，分析澳门城市空间如何通过路线、建筑、标识、声音、人流、商品和互动体验编排不同的跨文化身份。

---

## 核心论点

澳门的跨文化身份不是单一的“中西融合”，而是在不同城市空间中被有选择地展示、组织和体验。沿着我们的路线，口岸、历史遗产、商业街道、威尼斯人和 NBA 店分别把澳门编排为门槛空间、遗产空间、旅游街道和全球消费舞台。

## 方法说明

本项目没有进行正式访谈，不声称代表澳门居民、游客或商家的主观观点。分析集中于公共空间中可观察到的语言、建筑、声音、动线、人流和消费符号。AI 仅作为前期头脑风暴和语言辅助工具；最终研究问题、素材选择和分析框架来自实地材料和小组讨论。
