# 高分框架：Report 与 Presentation

## 一句话 thesis

澳门的跨文化身份不是一个固定的“中西融合”答案，而是在一条路线中被口岸、遗产地、街道、酒店综合体和互动消费空间连续编排出来的体验。

英文：

Macau's intercultural identity is not a fixed fusion, but a sequence of experiences staged through borders, heritage sites, streets, integrated resorts, and interactive consumer spaces.

## Report 高分逻辑

| 评分点 | 写法 |
|---|---|
| 清晰与连贯性 | 用一条路线串起四类空间，不罗列景点。 |
| 写作质量 | 正式学术语气，中文为主，关键术语中英对照。 |
| 内容深度 | 从“中西融合”转向 spatial curation / spatial translation。 |
| 研究准确性 | 使用至少 10 条学术来源，APA 7，素材用视频编号对应。 |
| 原创性 | 用 Threshold / Heritage / Street / Spectacle 四类空间解释澳门身份。 |
| 贡献说明 | 封面或附录填写成员贡献顺序。 |

## Report 必须做到

1. Introduction：提出问题，说明为什么“中西融合”不足。
2. Literature Review：综合空间理论、旅游真实性、语言景观、感官/行走方法、澳门研究。
3. Methodology：说明 direct observation、photo/video documentation、walking route analysis、sensory observation、无正式访谈。
4. Findings：每一类空间都用具体视频编号和图像证据支撑。
5. Discussion：展开综合论证，不重复 findings。
6. Conclusion：收束核心洞察，并说明局限与未来研究方向。

## Discussion 展开重点

| 小节 | 目标 |
|---|---|
| From Fusion to Sequenced Spatial Translations | 说明澳门不是一个静态融合标签，而是路线中连续切换的空间翻译。 |
| Inherited Heritage and Designed Spectacle | 对比大三巴/大炮台与威尼斯人/NBA 店：历史遗产 vs 设计体验。 |
| Intercultural Communication Beyond Language | 说明跨文化交流发生在排队、导视、台阶、招牌、屏幕、商品和身体动作中。 |
| Why the Route Matters | 说明路线方法如何避免旅游介绍，并承认游客视角与无访谈的局限。 |

## Presentation 高分逻辑

- 开头 30 秒让观众看到“路线切换”的节奏。
- 每页标题都写成 claim，不写成地点名称。
- 用大图、短视频或两图对比证明一句话。
- 图像不要平均分配，要服务论点。
- Q&A 准备围绕方法、素材选择、无访谈局限、为什么不是旅游介绍、为什么不是简单中西融合。
