# Presentation Package

## 主文件

- `Walking_Through_Many_Macaus_video_frames.pptx`：15 页新版最终展示 PPT，已优先使用高清视频抽帧并减少明显人物入镜。
- `Walking_Through_Many_Macaus.pptx`：旧文件名版本；若它正在被 PowerPoint 占用，可能尚未被新版覆盖。
- `speaker_script_zh_en.md`：逐页中英对照演讲稿与 Q&A。
- `assets/opening_montage.mp4`：开场 montage 视频，PPT 第 2 页已标注路径。

## 展示建议

1. 开场先播放 `assets/opening_montage.mp4`，再切回 PPT 第 3 页。
2. PPT 文案偏英文，讲稿以中文解释为主，适合组员先排练。
3. 总时长按当前讲稿约 19-20 分钟。
4. 如果课堂要求全英文展示，可基于 `speaker_script_zh_en.md` 里的英文句扩展。
