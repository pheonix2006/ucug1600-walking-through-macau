# Deep Research 参考摘要（已清理版）

> 用途：作为报告结构和资料补强的参考，不作为最终报告正文直接复制。

## 可采纳的方向

1. 报告应严格遵循学术结构：Introduction, Literature Review, Methodology, Findings, Discussion, Conclusion, References。
2. Literature Review 需要从“理论解释”升级为“文献综合”，至少覆盖空间理论、旅游真实性、语言景观、行走/感官方法、澳门遗产与旅游研究。
3. Findings 不应停留在描述景点，而应使用照片、视频和路线证据解释空间如何组织跨文化身份。
4. Discussion 应成为重点，回答“为什么这条路线能揭示澳门跨文化身份的空间编排”。
5. References 需要 APA 7 格式，学术文献为主体，官方资料只作为背景来源。

## 适配到本项目的章节逻辑

| 章节 | 写作重点 |
|---|---|
| Introduction | 从“中西融合”的常见叙事切入，提出空间编排问题。 |
| Literature Review | 综合空间生产、旅游凝视、真实性、语言景观、感官民族志和澳门研究。 |
| Methodology | 说明直接观察、照片/视频记录、路线分析、感官观察、无正式访谈。 |
| Findings | 用 Threshold / Heritage / Street / Spectacle 四类空间组织素材。 |
| Discussion | 展开“从 fusion 到 spatial translations”“遗产与奇观差异”“跨文化交流超越语言”“路线方法价值与局限”。 |
| Conclusion | 收束核心洞察，并提出未来研究方向。 |

## 风险提示

- 不虚构访谈、录音、问卷或居民观点。
- 不把澳门简化为单一“中西融合”标签。
- 不把素材当作景点罗列；每个图像和视频都要服务论点。
- 避免使用明显正脸、自拍和人物合影作为主视觉。

## 当前最佳使用方式

此文件只保留结构性参考。具体写作应以 `report/main.tex`、`notes/report_structure.md` 和 `notes/material_evidence_map.md` 为准。
