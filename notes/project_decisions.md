# 项目决策记录

## 已确认

- 过程文件优先中文。
- 英文内容需要尽量配中文对照。
- final report 更像研究报告。
- final presentation 更重视观众视听体验、清晰叙事和评分要求。
- 本项目不以访谈为方法核心，主要使用图片、视频和现场观察。
- 后续目录：
  - `report/` 放 LaTeX 报告和 PDF。
  - `slide/` 放 PPT、演讲稿和展示相关材料。
  - `notes/` 放讨论和临时分析。

## 待确认

- 最终主标题。
- 最终 research question。
- presentation 是否全英文展示，或中英混合。
- vlog/视频片段是否剪辑，以及放在 presentation 的哪个位置。
- report 是否需要参考文献与引用格式。
