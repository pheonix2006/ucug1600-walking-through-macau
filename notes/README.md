# Notes 使用地图

本目录保存项目讨论、结构框架、素材地图和写作工作稿。最终提交前，应以 `report/` 与 `slide/` 中的文件为准。

## 推荐阅读顺序

1. `project_decisions.md`：当前主题、研究问题、四类空间框架。
2. `high_score_framework.md`：report/presentation 如何对齐评分标准。
3. `report_recommended_structure_guide.md`：报告结构指南。
4. `report_structure.md`：当前 report 章节结构。
5. `material_evidence_map.md`：视频编号、地点、论点和素材使用建议。
6. `presentation_page_structure.md`：PPT 逐页结构。
7. `presentation_speaker_notes.md`：中英排练提示。

## 写作底线

- 不虚构访谈、录音或问卷。
- 不把游客、居民或商家主观感受写成我们已经调查过的结论。
- 素材分析必须能对应照片、视频或路线观察。
- 图片和视频优先展示空间、标识、建筑、人流整体、商品陈列和互动设施。
